# v23 — materiały do sesji SWV1–SWV5

Folder przejściowy (jak dawniej `seed-v22/`). Każda sesja przenosi swoje pliki na właściwe miejsce i usuwa je stąd; po SWV5 zostaje tylko ten README albo folder znika.

| Plik | Co to | Sesja |
|---|---|---|
| `zz_v23.css` | Warstwa kolorów, telefonu i ruchu z wizualizacji v23 — **opis efektu, nie do wklejenia** (zasady → tokeny i komponenty) | SWV1, SWV3, SWV5 |
| `v23_thumbs.py` | Podmiana kolorów tła miniatur (wzorzec skryptu dla `public/software/rozwiazania/*.svg`) | SWV1 |
| `osm_rabka.json` | Dane OpenStreetMap okolicy Orkana 16B, już rzutowane na 800 × 560 (ścieżki SVG wg klas: budynki, ulice 1–4, tory, rzeka, zieleń, parkingi; budynek docelowy, etykiety). © autorzy OpenStreetMap, ODbL | SWV4 |
| `mk_map.py` | Skrypt wizualizacji: z `osm_rabka.json` składa `map.svg` + `map.css` | SWV4 |
| `map.svg`, `map.css` | Gotowa mapa i jej kolory (motyw jasny i ciemny) — wzorzec wyglądu | SWV4 |
| `pkScroll.js` | Przewijanie szyny sekcji z hamowaniem i „przyjazdem” nagłówka | SWV5 |
| `img/krystian.jpg`, `img/tadeusz.jpg` | Portrety (640 × 640) do O firmie | SWV4 |
| `img/wejscie.jpg` | Zdjęcie wejścia przy ul. Orkana 16B (kontakt, O firmie, Jedna firma) | SWV4 |

Zgoda na wizerunek obu osób — wymagana przed produkcją (STAN).
